## 7. Phase-B by-pointer arm duplicates the by-word arm's scaffolding

- **Location:** `/mnt/ch/ClickHouse/src/Interpreters/HashJoin/HashJoinRoutedMethodsImpl.h:364-391`.
- **What:** The two arms share everything - `if (const UInt64 word = ...)`,
  `right_row_found = true`, the `FindResult` construction, and a byte-identical
  14-argument `processMatch` call - and differ only in how the mapped pointer is
  derived (rebuild a local from the word vs `reinterpret_cast` the word). The
  second `processMatch` call site is pure duplication.
- **Why non-behavioral:** for every existing instantiation the merged form emits
  the same calls with the same arguments. ASOF is instantiated only with
  `need_flags == false` (see the `MapsAsof` rows of the macro and the
  "never flagged" comment), so the shared `offset` variable stays 0 there -
  identical to today's literal `0`.
- **Suggested change (shape):**
  ```cpp
  if (const UInt64 word = found_words[i])
  {
      right_row_found = true;
      size_t offset = 0;
      if constexpr (join_features.need_flags)
          offset = found_offsets[i];
      auto emit = [&](Mapped * mapped) ALWAYS_INLINE
      {
          typename KeyGetter::FindResult find_result(mapped, true, offset);
          processMatch<...>(find_result, added_columns,
              *flags_data[slot_ids ? slot_ids[ind] : 0], i, ind, current_offset, dummy_known_rows);
      };
      if constexpr (amac_mapped_fits_word<std::remove_const_t<Mapped>>)
      {
          auto mapped_value = mappedFromWord<std::remove_const_t<Mapped>>(word);
          emit(&mapped_value);
      }
      else /// ASOF: the find pass recorded the mapped value's address (maps immutable)
          emit(reinterpret_cast<Mapped *>(word));
  }
  ```
  The `else if constexpr (amac_mapped_by_pointer...)` becomes a plain `else`:
  the `precomputed` loop is only instantiated under `amac_probe_supported`,
  which is exactly `fits_word || by_pointer` (the existing `static_assert` can
  state this for the reader). Saves ~10 lines and the second call site.
  The lambda (rather than a hoisted `Mapped` local) avoids default-constructing
  a dead `AsofRowRefs` in the pointer arm.

## 9. Test-side helper duplication

- **Teeth test** (`/mnt/ch/ClickHouse/src/Interpreters/tests/gtest_amac_wrapped_walk.cpp`):
  no finding. It is self-contained (its only helper is `DegenerateHash`), shares
  nothing with the main gtest's `ConcurrentHashJoin`-level helpers, and the
  separate TU is the right layering: it must include `AmacProbeImpl.h` (the
  template body) to instantiate an adversarial map, which the end-to-end gtest
  TU has no reason to compile. Unit tests are auto-globbed, so no build wiring
  accreted either.
- **`makeAsofBlock`** (`/mnt/ch/ClickHouse/src/Interpreters/tests/gtest_concurrent_hash_join_amac.cpp:788-806`,
  from 633cca): a 19-line three-column clone of the file's `makeKeyBlock`
  (line 49). It can reuse it:
  ```cpp
  Block block = makeKeyBlock(key_name, id_name, keys, ids);
  auto asof_column = ColumnUInt64::create();
  asof_column->getData().assign(asofs.begin(), asofs.end());
  block.insert(1, {std::move(asof_column), std::make_shared<DataTypeUInt64>(), asof_name});
  return block;
  ```
  Same (key, asof, id) layout via `Block::insert(position, elem)`; the test's
  assertions and data are untouched. Optional. (`runAsofProbe` intentionally not
  folded into `buildJoin` - generalizing `buildJoin` for the second key +
