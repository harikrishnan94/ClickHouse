### 3. MINOR — `asmdiff.py` branch classifier counts ALU ops as branches
`tmp/chj_amac/asmdiff/asmdiff.py:67`

`k.startswith(("b.", "b", ...))` — the bare `"b"` prefix subsumes `"b."`,
`"bl"`, `"br"` (dead entries) and also matches `bic`, `bfi`, `bfxil`, `bfm`
(ALU ops), inflating the printed `branches=` field. The bias is identical in
before/after so the gate's opcode-delta conclusion stands, but the absolute
number quoted per binary is wrong. Rewrite:

```python
branches = sum(v for k, v in ops.items()
               if k.startswith("b.") or k in ("b", "bl", "blr", "br", "ret", "cbz", "cbnz", "tbz", "tbnz"))
```

### 4. MINOR — `asmdiff.py` mnemonic regex drops operand-less instructions
`tmp/chj_amac/asmdiff/asmdiff.py:57`

`r"^([a-z][a-z0-9.]*)\s"` requires trailing whitespace, so a stripped `ret`
or `nop` line never matches: they vanish from the histogram and totals, and
the `"ret"` entry in the branch list (:67) can never fire. Rewrite:
`re.match(r"^([a-z][a-z0-9.]*)(?:\s|$)", line)`.
