### 4. Should a missing frozen `matrix.json` silently regenerate the universe? (fallback + import cycle vs the harness's own fail-closed rule)

- **Where:** `fleet_ab.py:1374-1381` (`default_plan_cells`: if
  `fleet/matrix.json` is missing, `sys.path` juggling + lazy
  `import matrix_gen` and regenerate the cell list on the fly).
- **Shape:** error-masking-adjacent fallback + sequencing scaffolding (the
  lazy import exists only to dodge the cycle the fallback itself creates:
  "Lazy import to avoid a module-level cycle (matrix_gen imports fleet_ab)",
  fleet_ab.py:1378).
- **Evidence:** this is a guard/fallback, so per the hard rules it is not
  flagged as removable — the missing-file state is reachable (a deleted or
  partially-copied checkout). But the arm's two reachable outcomes are both
  wrong-shaped: (a) on the orchestration host it silently substitutes
  whatever the *current* generator emits for the *frozen* registration
  (MATRIX.md:6-8 and WORKLOG.md:249 define `fleet/matrix.json` as the frozen
  coverage universe; today generator == file, verified mechanically, but the
  freeze exists precisely for when they stop agreeing); (b) on a deployed
  shard the fallback cannot work at all — `fleet/deploy.sh:22` ships neither
  `matrix.json` nor `matrix_gen.py`, so a remote `sweep --shard` without
  `--cells` dies on `ImportError` instead of a clear message. The component's
  own accepted review policy is fail-closed on missing inputs
  (`load_result_rows`, fleet_ab.py:1185-1188, review finding 5).
- **Impact:** obscured information: a reader (and a shard operator) must
  know that "no matrix.json" flips the cell source from frozen data to live
  code — the one substitution a prereg freeze exists to prevent.
- **Cleaner shape (if the answer is "no"):** replace the fallback arm with
  `raise SystemExit("ERROR: fleet/matrix.json missing (frozen universe; "
  "regenerate deliberately via fleet/matrix_gen.py)")` — this also deletes
  the lazy-import machinery and the module cycle with it.
- **Behavior preservation:** only the missing-file path changes; every
  recorded run had `matrix.json` present. No test covers the missing-file
  path today.
- **Severity × disposition:** question for the author (ambiguous verdict —
